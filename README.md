# Universal Display Lib

A Vintage Story library for display blocks: free item placement, stacking, rotation, lighting and particles on surfaces you mark in your shape file, with selection and collision boxes measured from the model.

- Mod page: https://mods.vintagestory.at/universaldisplaylib
